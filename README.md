## Quick OS DL API

This API will allow callers to find URLs and other information for downloading a specific OS version.

Documentation will be provided later down the line.

It's not recommended to use this API in production; it's purely a proof of concept.

The data used for this API is pulled from the [quickget_cigo](https://github.com/lj3954/quickget_cigo) project,
and can be used directly by applications instead. Other projects, such as the unrelated [quickosdl](https://github.com/lj3954/quickosdl),
make use of this data directly. This API will not do anything other than serving the same data to callers.
